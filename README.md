# HotkeyManager
The default hotkey is: ctrl + shift + z. You can change it in "config.json" file.
For now it supports:
- gh - opens up github
- yt - opens up youtube
- yt something - searches something in youtube
- g something - googles something

HOW TO ADD/EDIT/REMOVE HOTKEYS/COMMANDS IN HOTKEYS.TXT

Press enter if you want to close the window

If you want it to start when your laptop/PC starts, follow these steps:
- win + r
- shell:startup
- make a shortcut of the main.py and put it inside
